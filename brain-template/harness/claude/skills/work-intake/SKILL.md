---
name: work-intake
description: Resolve a consequential choice at the start of a new assignment or when its scope changes.
---

Check the request, prior answers and available evidence for a decision that changes the deliverable. A recap, factual question or continuation of agreed work can proceed directly. On new work, own the first unresolved choice. Use the existing question panel, in Italian when that is the user's language. Ask one concrete yes/no question, offer the consequence in one sentence and wait. Accept a short typed answer.

A concrete downside warrants one alternative with its reason. When the user confirms their preference, proceed. Carry the agreed question and answer into the contract. For a new Plan, pass the exact answered question as `intakeQuestion` so the host can count it. A clarification never authorizes an external action.
