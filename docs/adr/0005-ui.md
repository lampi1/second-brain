# ADR 0005 · UI: two workspace views (Mosaico, Corsie), always-on Regia tile, needs-you first

Date: 2026-10-11 · Status: accepted

## Context
The user asked for a clean, calm modern desktop UI (few, useful notifications), not the site style; chats as tiles each with an always-active input;
several browsers visible at once; a Regia box always available and recognizable; "mi piacciono molto entrambi" →
both views with a remembered preference, Mosaico by default. Research on 17 harness apps: the "needs you" signal is the
weakest point everywhere; best ideas: needs-you lane on top, one hotkey to the next thing, answer from the list with
1-9/Enter/Esc, recap on return, calm notifications, focus mode, auto-tidy of finished chats.

## Decision
- Views: **Mosaico** (needs-you lane on top; grid of Regia + chat tiles + browser tiles next to their chats) and
  **Corsie** (columns by state; browser strip). Toggle in the top bar and `Ctrl+Shift+V`; stored in config.
- Mosaico zones (user, 2026-10-12, "browser e chat separati un pelo più in ordine"; chosen among zones / pair in one
  cell / column per chat): chats in a grid on the left, browsers in their own grid on the right in their chats' order,
  tied by the pair color, a splitter between the zones. **Nascondi browser** (top bar, `Ctrl+Shift+B`, remembered)
  drops every browser tile (Mosaico, Corsie, focus) so the chats take the room; tabs keep working parked off screen,
  and a tab with an open hand-off stays visible.
- Regia tile: fixed position (left), violet, own name; default input focus. (Superseded by ADR 0021: a floating
  overlay with one tab per Regia.)
- Every chat tile: header (harness logo, title, state, stop, maximize), sub-line (model · effort · cost · folder),
  collapsible tool rows with diff counts, inline question/permission panel, always-visible input.
- Keyboard: `Ctrl+K` palette/search, `Ctrl+J` next thing that needs you, `1-9` / `Enter` / `Esc` on the focused
  request, `Ctrl+.` stop focused chat, `Ctrl+Shift+.` stop all, `F11`/`⤢` maximize a tile.
- Brain pages (oggi, da fare, idee e spunti, costi, qualità, diario, esplora, mappa 3D) are app pages in the same
  style, fed by the brain adapters.

## Consequences
- Tiles must stay readable at small sizes: collapsed rendering shows the last line + the open request only.

## Update 2026-10-13: no "Finite oggi"
The user: "anche le finite oggi levale non mi piacciono molto non le uso mai"; "mi basta trovarle nella barra di
ricerca". The auto-tidy is now only the auto-close (`lib/autoclose.ts`): the Mosaico's "Finite oggi" dock, the Corsie
"Finite oggi" column (with its "Precedenti") and the "Chiuse" list are gone. Corsie has two columns, "Ti aspettano" and
"Al lavoro" (busy chats, then the finished ones still open). A finished chat stays a tile for a short grace period
(setting `autoCloseMin`, default 2 minutes, in Impostazioni → Chat; restarted by any touch on its tile) and then closes
by itself, unless something holds it (a request, queued message, draft, running background task, hand-off or browser in
use, maximized/selected/focus mode; the Regia and an interrupted or failed chat never close). Closed chats are found
only with Ctrl+K (palette group "Chiuse"; Enter reopens with the history).
