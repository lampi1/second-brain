# 0220 — Scoped role skills and verified Plan intake

Accepted. Supersedes the agent-supplied shortcut in ADR 0209. Each role has a small set of shipped, on-demand skills. A Strategist may reuse one host-verified intake answer from the Orchestrator. Three distinct answers, an explicit user stop or the existing night policy govern presentation of the plan. The plan approval and external-action boundaries keep their existing gates.

The [design and source inventory](../design/skills-alignment.md) records role assignments, rejected workflows, token estimates and acceptance scenarios.
