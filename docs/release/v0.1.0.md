# second-brain 0.1.0

The first release of second-brain: a desktop app for Windows that puts all your AI agents in one place.

## What it is

You work with several AI agents at once (Claude Code, Codex, Cursor). second-brain shows every agent as a strip on one
screen. It collects their questions and permission requests so you answer them from one place, and it shows the
browsers the agents drive. A coordinating chat, the **Orchestrator**, plans the work, opens the chats and tells you
what needs you next.

The app starts the official command-line tools with your own login and never changes their settings.

Everything the agents learn goes into your **brain**: a folder of notes, rules and small tools that you own. The app
creates it for you on first launch, or uses one you already have.

The interface is in Italian or English (Settings → Lingua; by default it follows Windows).

## What you can do

**Agents**
- **Grindhouse (home page):** one strip per working agent, grouped by project, with its state, cost and last answer.
  Open a strip to read the conversation and write to it. The browser an agent drives sits right under it.
- **Orchestrator:** a chat always open in the right column. Tell it what you want; it picks an agent from your catalog
  (or a general one) and opens the work chat for you.
- **Agent catalog («Gestisci agenti»):**
  - six ready-made agents (Assistant, Research, Writing, Analysis, Planning, Development);
  - create your own, optionally from a draft the AI writes for you;
  - every change is a new version you can go back to;
  - each agent has limits on what it may do without asking.
- **Runs and metrics:** each assignment of a catalog agent is recorded as a run: questions asked, permissions,
  corrections, cost, time and how it ended. Chats you open without picking an agent are counted too, as the general
  agent. Costs per agent are shown on the Costi page.
- **Probation:** an agent can be kept on trial and is then kept or retired based on its runs. In this release the app
  does the bookkeeping; creating agents on trial and the approval list come later.
- **Personal milestones:** first custom agent, workspace set up, first confirmed result.

**Questions and permissions**
- When an agent asks something or wants to run a command, it shows up as a panel in its strip. Answer with one key.
- Turn on «Popup» in the top bar to get questions one at a time in a central window instead.
- «Rispondi dopo» parks everything in a list without interrupting you. Ctrl+J takes you to the next thing waiting for
  you.
- Nothing is answered for you, and nothing expires.

**Your brain**
- Pages for what the brain holds: ideas, procedures, learned rules, and the 3D map that lights up where agents work.
- **Search (Ctrl+K)** finds chats, messages, branches and notes:
  - brain notes are searched by words and by meaning, offline, so a paraphrase or the other language still finds them;
  - typos are tolerated.
- **Themes (Dashboard):** recurring agent errors and ideas grouped by topic, with growing themes and near-duplicates
  flagged.
- **Error recall:** when a new task looks like a mistake agents made before, the chat gets a short warning first.

**Files**
- One built-in, read-only viewer for every file link in chats, questions and procedures:
  - code with syntax highlighting;
  - CSV and JSON as tables, Markdown rendered;
  - PDFs;
  - large logs read page by page, opening at the cited line.
- **Confronta:** compare a file with its last committed version, a commit or branch you type, or another file.
- The viewer never opens or runs the file.

**Costs and limits**
- The top bar shows today's spend, the 5-hour and weekly windows of your plan, and the most expensive chats.
- You can set daily and per-chat spending limits. You get a warning at 80% and 100%.

**Help**
- **Guida:** a page (left rail, or Ctrl+K "guida") that explains each part of the app in plain words, with the
  technical details for the curious. «Discutine» opens a chat about any topic.

## Known limits

- **Windows only.** Windows 10 and 11 (x64). Linux and macOS builds exist but have not been tried on a real machine.
- **Updates are not installed automatically yet.** The app downloads and prepares a new version in the background
  («Aggiornamenti»), but does not install it. To update, download and run the new Setup.
- **Codex support is new:** it has been built and tested against the Codex protocol, not yet with a real Codex CLI run.
- **Claude is the default engine.** With only Codex or only Cursor, new chats, the starter agents and the chats the
  Orchestrator opens still try Claude at first. Turn your engine on in Settings → Motori, turn Claude off, choose your
  engine for «Chat aperte dall'Orchestrator», and change the starter agents' engine. Chats about the app itself
  («Migliora l'app») run only on Claude.
- **Some features work only with Claude today:**
  - error recall warns only Claude chats;
  - the hourly headline on the home page is written by a model only with an Anthropic API key, and so is the AI draft
    of a new agent;
  - correcting an agent «at the next step» works only on Claude;
  - after a restart, the history of a closed Codex or Cursor chat stays empty until you reopen it, and search finds
    only its title.
- **More clicks on Codex and Cursor:** the app's own tools (opening chats, driving the browser) are pre-approved only on
  Claude. On Codex and Cursor each use asks for permission.
- **Costs:** Codex chats show no cost, and the top bar and spending limits cover Claude and Cursor only. Cursor costs
  are estimates.
- **First search setup:** meaning search downloads a 135 MB model once and reads your brain in the background for a
  few minutes. Until then, search works by words only.
- **Spending limits warn, they never stop a chat.**
- **Agents can only suggest new agents.** The Orchestrator cannot create one by itself; you save new agents in
  «Gestisci agenti».
- **Agent limits:** Claude enforces all of an agent's limits. Codex and Cursor enforce only part of them (Cursor only
  "plan only"), and Cursor's "allow always" option is not offered.
- **The DevOps page needs a script in your brain**, and reads Azure DevOps only.
- This is an early release of a personal project, provided as is, without warranty.

## Requirements

- Windows 10 or 11, 64-bit.
- At least one engine, signed in with your own account:
  - **Claude Code** (included in the installer; sign in on first use), and/or
  - **Codex CLI** (`codex`; turn it on in Settings → Motori), and/or
  - **Cursor CLI** (`agent`).

  The app never asks for or stores your engine password. You can also add an Anthropic or other API key in
  Settings → Motori; it is stored encrypted.
- 135 MB of disk for the search model, besides the app itself.
- Git is optional: needed for «Confronta» and for brain sync between PCs.

## How to install

1. Download the `…-windows-x64-setup.exe` file from the 0.1.0 release page.
2. Optional: check the file against the SHA256 checksum published next to it.
3. Run the Setup. It installs for your user only (no administrator rights, no Node.js) and creates Start Menu and
   desktop shortcuts.
4. On first launch:
   - create your brain or pick an existing folder;
   - answer the short first interview;
   - sign in to at least one engine.
5. Start the Orchestrator in the right column and tell it what you want to do.

To uninstall, use Windows' Apps settings. Your chats (`%APPDATA%\second-brain`) and your brain folder are kept.
